## 📌 Project Overview

The Sales Forecasting System predicts future sales using historical sales data and machine learning techniques. The project analyzes monthly sales trends, builds a forecasting model using Linear Regression, and provides business insights through visualizations.

---

## 🎯 Objectives

* Analyze historical sales data.
* Clean and preprocess the dataset.
* Identify monthly and yearly sales trends.
* Build a forecasting model using Linear Regression.
* Visualize actual vs predicted sales.
* Generate business recommendations.
